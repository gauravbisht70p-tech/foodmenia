# 🍔 Foodmenia

A modern food discovery web application built with **React.js**. Foodmenia allows users to explore restaurants, browse food options, and quickly filter restaurants based on their ratings.

## 🚀 Features

- 🍽️ Browse restaurant listings
- ⭐ **Top Rated Restaurants** filter
- 🔍 Search and explore restaurants
- 📱 Responsive user interface
- ⚡ Fast and dynamic UI using React
- 🧩 Reusable React components
- 📦 Restaurant data fetched from an API
- 🔄 Dynamic rendering using React

## 🛠️ Tech Stack

- **React.js**
- **JavaScript**
- **HTML5**
- **CSS3**
- **Vite**
- **REST API**
- **Git & GitHub**

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/gauravbisht70p-tech/foodmenia.git
```

### 2. Navigate to the project

```bash
cd foodmenia
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local development URL shown in your terminal.

## ⭐ Top Rated Filter

Foodmenia includes a **Top Rated** filter that allows users to quickly view highly-rated restaurants.

The filter dynamically updates the restaurant list based on the restaurant's rating.

```text
All Restaurants
       ↓
Top Rated
       ↓
Highly Rated Restaurants
```
